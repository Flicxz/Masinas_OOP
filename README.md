# Objektorientēta mašīnas programma
## Garāžas programma par mašīnām, kas beigās ļaus uztaisīt mašīnu, modificēt tās ātrumu, parādīt savu ātrumu, un taisīt vairākas tādas mašīnas.
### Funkcijas
[x] Izveidot mašīnu  
[x] Saglabāt failā  
[x] Nolasīt failu  
[x] Noteikt ātrumu  
[x] Samainīt parametrus  
[x] Izbraukt  
[x] Apskatīt gatavās mašīnas  
[ ] Izvēlēties no faila mašīnu  
[x] Pārkrāsot mašīnu
